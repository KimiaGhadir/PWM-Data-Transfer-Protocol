# پروتکل انتقال داده با استفاده از PWM

## توضیحات پروژه
در این پروژه یک پروتکل ساده برای **ارسال و دریافت داده دیجیتال با استفاده از PWM** طراحی شده است.  
این ارتباط تنها با استفاده از **یک پین PWM** بین دو دستگاه انجام می‌شود.

به جای استفاده از سخت‌افزار واقعی، کل سیستم در محیط **Proteus** شبیه‌سازی شده است.

## اهداف پروژه
- طراحی یک کانال ارتباطی مبتنی بر PWM  
- ارسال داده دیجیتال با استفاده از تغییر سیکل کاری PWM  
- پیاده‌سازی هم‌گام‌سازی بین فرستنده و گیرنده  
- استفاده از روش‌های ساده برای تشخیص خطا  
- تست و اجرا در Proteus بدون نیاز به بورد آردوینو فیزیکی  

## نحوه عملکرد
داده دیجیتال به کمک **تغییر Duty Cycle** کدگذاری می‌شود.  
گیرنده با اندازه‌گیری سیکل کاری PWM، مقدار بیت را تشخیص می‌دهد.

مثال از کدگذاری:
- مقدار «0» منطقی → سیکل کاری 25٪  
- مقدار «1» منطقی → سیکل کاری 75٪  

گیرنده با اندازه‌گیری سیکل کاری، بیت را تشخیص داده و بازسازی می‌کند.

## ساختار فریم داده
هر فریم ارسالی شامل بخش‌های زیر است:

- **بایت شروع (Start Field)** → تشخیص آغاز فریم  
- **فیلد داده (Data Field)** → شامل بیت‌ها یا بایت‌های اصلی  
- **فیلد بررسی خطا (Error Check)** → مانند parity یا checksum  
- **فیلد پایان (Stop Field)** → پایان فریم  

## هم‌گام‌سازی (Synchronization)
همگام‌سازی توسط یک الگوی PWM مشخص برای شروع فریم انجام می‌شود.  
گیرنده ابتدا این الگو را شناسایی کرده و سپس آماده خواندن بیت‌های بعدی می‌شود.

## تشخیص خطا
برای تشخیص خطا از روش‌های ساده مانند:
- **بیت توازن (Parity Bit)**  
یا  
- **Checksum ساده**

استفاده شده است.  
اگر مقدار محاسبه‌شده و مقدار دریافتی مطابقت نداشته باشد، فریم نامعتبر در نظر گرفته می‌شود.

## شبیه‌سازی در Proteus
این پروژه کاملاً در Proteus شبیه‌سازی شده است.

مراحل اجرا:
1. پروژه Proteus را باز کنید  
2. فایل HEX برنامه آردوینو را روی Arduino در Proteus بارگذاری کنید  
3. شبیه‌سازی را اجرا کنید  
4. مقادیر PWM و خروجی گیرنده را مشاهده کنید  

## ابزارهای استفاده‌شده
- Proteus  
- Arduino IDE  
- زبان C/C++ برای آردوینو
